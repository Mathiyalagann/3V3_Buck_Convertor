# 3.3V Buck-Boost PCB Converter -ALtium Designer

## 📌 Overview

This project focuses on designing a **3.3V Buck-Boost DC-DC Converter PCB using Altium Designer**.

The design uses the **TPS630252 Buck-Boost Converter IC** to generate a stable 3.3V output from a varying input voltage.

The project involves schematic design, component footprint selection, PCB layout, component placement, routing, and design verification.

The objective is to gain practical experience in DC-DC power supply design and professional PCB design using Altium Designer.

## 🛠 Tools & Standards Used

- Altium Designer 25.4.2– Schematic Capture and PCB Layout
- IPC-7351 – Component Footprint and Land Pattern Guidelines
- IPC-2221 – Generic PCB Design Guidelines

## ⚡ Design Description

- **OUTPUT VOLTAGE:** 3.3V DC.
- **CONTROLLER IC:** TPS630252.
- **PCB COUNT:** 4-Layer. 
- **PCB Thickness:** 1.6 MM. 
- **Layer Stackup:** Top Signal, Ground, Power, and Bottom Signal.
- **FOOTPRINT SELECTION:** Component footprints based on manufacturer datasheets and IPC-7351 guidelines.
- **PCB LAYOUT:** Component placement, power routing, signal routing, clearance, and spacing.
- **DESIGN VERIFICATION:** Electrical Rule Check (ERC) and Design Rule Check (DRC).
